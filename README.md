# Cincinnati Document Services

Mobile notary, photo restoration, document scanning, digitizing, printing, and digital archival services in Greater Cincinnati. We bring the office to you.

**Website:** [cincydocs.com](https://cincydocs.com) | **Call/Text:** 513 580 4150

---

## Repository Structure

| Directory | Purpose |
|-----------|---------|
| `docs/`   | GitHub Pages website (deployed to cincydocs.com) |
| `tools/`  | Open source Python tools and utilities |

The site is a static HTML/CSS site deployed from the `docs/` folder via GitHub Pages. The `tools/` directory is not served by Pages — it contains open source utilities related to document services, archiving, and automation.

## Tools

Python-based utilities for document processing, photo restoration pipelines, and archival automation. See `tools/` for individual tool documentation.
